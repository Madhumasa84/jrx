# Verification and fixes — 2026-10-18

Tested the current working tree on Linux with Python 3.11.15, real Docker,
Gitleaks, Helm, and checksum-verified Cosign v3.0.5. Existing unrelated changes
were preserved.

## Fixes

- Malformed explicitly typed YAML could crash policy linting and both runtime
  configuration loaders. Invalid boolean/timestamp tags and empty numeric tags
  now produce normal validation errors.
- Numeric conversion errors could include configuration values in diagnostics.
  These parser failures now produce generic, value-free messages.
- Collection tags applied to scalar mapping keys could produce unhashable Python
  objects and crash linting. The linter now rejects these keys before duplicate
  checking.
- Two MCP integration tests exceeded their outer subprocess deadlines during a
  concurrent container build. Their deadlines now allow CLI startup and local
  scanning on a busy host. The gateway's tested 0.2-second upstream timeout and
  all authorization assertions remain unchanged.

Added 29 regression cases. All failed against the relevant pre-fix behavior.
The focused configuration/policy suite passed all 83 tests. An additional 612
generated typed-YAML cases returned structured lint diagnostics without crashes.
