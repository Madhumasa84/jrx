### Development checks and retries

- The initial replay regression run had 10 expected failures. An intermediate run found two audit-report compatibility failures among 120 tests. Both were corrected. A socket-restricted run passed 127 of 128. All 128 passed with host sockets. A separate invalid-YAML regression failed before the diagnostic fix. The final focused replay suite passed all 11 cases.
- Workflow tests failed against the original single job, then passed 18 intermediate and 20 final cases. Focused isolation/output runs passed 20, 30, 21, 21 and 21 tests as fixtures moved. Two intermediate Ruff import-order diagnostics were corrected. The integrated Phase 2 replay/PR selection passed 61 of 61. The full Phase 2 suite collected before the final simulation diagnostic test was added. That test passed in the focused run and both subsequent full runs.
- The first cache-only development dependency install lacked the build backend. Installing the declared dependencies with registry access succeeded. The first JEV call hit restricted DNS. The permitted network rerun returned the recorded scores.
