## Publication

After review, use `git commit --signoff` for the release preparation commit. Confirm the pull request satisfies the repository's required checks and DCO sign-offs before merging. Set `RELEASE_PR` to the reviewed pull request number after it lands on `main`.

```bash
test "$(gh pr view "${RELEASE_PR:?set the reviewed release PR number}" --json state --jq .state)" = MERGED &&
  release_commit=$(gh pr view "$RELEASE_PR" --json mergeCommit --jq .mergeCommit.oid) &&
  git fetch origin main &&
  git merge-base --is-ancestor "$release_commit" origin/main &&
  git tag -a v0.3.0 "$release_commit" -m 'JEV Reflex v0.3.0' &&
  git push origin refs/tags/v0.3.0
```

The tag triggers the GitHub release workflow. The workflow verifies the installed version, publishes the broker image to GHCR, signs its digest, and attaches the SBOM, wheel, and sdist to the GitHub release. After the workflow succeeds, verify the image and upload the same validated Python artifacts to PyPI. [Release workflow](../../.github/workflows/release.yml)

```bash
release_commit=$(git rev-list -1 refs/tags/v0.3.0) &&
  release_run=$(gh api 'repos/{owner}/{repo}/actions/workflows/release.yml/runs' \
    --method GET -f event=push -f branch=v0.3.0 -f head_sha="$release_commit" \
    -f per_page=1 --jq '.workflow_runs[0].id // empty') &&
  test -n "$release_run" &&
  gh run watch "$release_run" --exit-status &&
  gh release view v0.3.0 &&
  docker buildx imagetools inspect ghcr.io/madhumasa84/jrx-broker:0.3.0 &&
  release_dist=$(mktemp -d) &&
  gh release download v0.3.0 --dir "$release_dist" \
    --pattern 'jev_reflex-0.3.0-py3-none-any.whl' --pattern 'jev_reflex-0.3.0.tar.gz' &&
  uvx --from twine twine check --strict "$release_dist"/* &&
  uvx --from twine twine upload --repository pypi "$release_dist"/*
```
